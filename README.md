# Project Joan

Version: v1.0 Beta

## Overview

Project Joan is an offline-first Progressive Web App (PWA) designed to generate high-quality A4 passport photo print sheets directly on mobile devices.

The application works completely inside the browser without uploading photos to any server.

Everything is processed locally.

---

## Features

- Passport Photo PDF
- JPG Export
- JPEG Export
- Automatic A4 Layout
- Custom Photo Size
- Custom Copy Count
- Auto Fill Maximum
- Cut Guide Lines
- High Quality Output
- Offline Support
- Progressive Web App (PWA)

---

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- jsPDF
- Service Worker
- Web App Manifest
